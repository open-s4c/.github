# Open S4C -- Safe and Scalable System Software Concurrency

Open S4C is an open collaboration dedicated to advancing safe and scalable concurrency in system software. 
Originally started as a research group, it has evolved into a community of researchers and engineers 
from various universities and industries.

For the most up-to-date documentation, project overviews, and resources, please visit: **[open-s4c.github.io](https://open-s4c.github.io)**
